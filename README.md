# PRIMEVAL

A 2D survival game inspired by Ark: Survival Evolved. Punch trees, craft tools, tame dinosaurs, build a base, and take down the Alpha Rex.

**Play:** https://iamno1special.github.io/primeval/

## Controls
- **Desktop:** WASD/arrows to move, mouse to aim, click to attack/harvest, E to interact, Shift to sprint, 1-6 hotbar
- **Mobile:** left joystick to move, right buttons to sprint / attack / use, tap hotbar slots

Saves live in your browser (autosaves every 15s). Phone and desktop keep separate saves.
